# Smart Home Thermostat Widget

This project is a web-based thermostat widget for managing room temperatures in a smart home. It allows users to view and control the temperature of different rooms, set presets, and toggle air conditioning.

## Features

- **Room Temperature Control**: Adjust the temperature of individual rooms.
- **Preset Management**: Configure and save cool and warm temperature presets.
- **Room Selection**: Switch between different rooms to manage their settings.
- **Air Conditioner Toggle**: Turn the air conditioner on or off for each room.
- **Dynamic UI**: Displays room-specific images and overlays based on the current temperature.
